Vice Cover Studio — an offline web app that turns your photo and a caption into GTA-style multi-panel cover art: pick a 3-panel poster, a 5-panel collage or a solo full-bleed layout, drop in up to 4 photos, crop and position each panel by dragging, write the title, pick a Vice Sunset, Neon Nights or Leonida Heat grade, and export a PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080. Everything runs from static files in your browser; photos never leave the machine. All lettering is drawn on canvas with system fonts, and all art is original.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Load a photo (or a built-in sample), pick a layout and grade, edit the caption, and export.
